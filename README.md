# Bexon - Corporate Business React Landing Page

A modern, high-performance corporate business landing page template built with **React.js**, **Vite**, and **GSAP (GreenSock Animation Platform)**. This project transforms a professional HTML template into a modular, interactive React single-page application.

## ✨ Key Features
- ⚡ **Advanced Text Animations:** Smooth character-by-character reveals using GSAP `SplitText` and `ScrollTrigger`.
- 📱 **Fully Responsive Layout:** Built using Bootstrap 5 grid systems, customized for mobile, tablet, and desktop viewports.
- 🔄 **Interactive Swiper Sliders:** Integrated continuous marquee ticker and showcase sliders.
- 📂 **Dynamic Content Sections:** Pre-built homepages, inner pages preview grids, and feature blocks.
- ❓ **Custom Styled FAQ Accordion:** Interactive collapsible sections with smooth styling and dynamic indicators.
- 🎯 **Sticky Navigation Header:** Dynamic scroll detection for fixed header transitions and mobile hamburger drawer.

## 🛠️ Tech Stack
- **Library:** React.js (v18+)
- **Build Tool:** Vite
- **Styling:** Bootstrap 5, Custom CSS (`App.css`)
- **Animations:** GSAP (ScrollTrigger, SplitText), Animate.css
- **Sliders:** Swiper.js
- **Icons:** React Icons (`react-icons`)
